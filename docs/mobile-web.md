# 移动端网页手动验收

适配范围：767px 及以下使用抽屉侧栏、紧凑顶栏和完整宽度的聊天区；触屏提供常显操作入口。沿用桌面组件和主题。

类型检查和构建不能代替真机验收。以下页面效果尚需用户在 iOS Safari 与 Android Chrome 实际确认。

| 操作 | 预期结果 |
| --- | --- |
| 320 / 375 / 390 / 430px 宽打开网页 | 初始收起侧栏、隐藏桌面图标栏，无整页横向溢出；不会自动唤起键盘 |
| 点击顶栏侧栏按钮 | 侧栏覆盖聊天区而非挤压；背景聊天区不能操作；关闭按钮、遮罩均可关闭 |
| 侧栏选择会话、新建会话、点击当前会话 | 侧栏关闭，显示所选会话；已有内容不丢失 |
| 侧栏操作会话更多菜单、置顶、添加项目 | 无需鼠标悬停即可发现并使用；长列表可以滚动 |
| 点击输入框，软键盘展开/收起 | 输入框、发送按钮保持可达；刘海和底部手势区不遮挡控件 |
| 软键盘回车、中文输入法选词 | 回车换行，选词不误发送；点发送按钮才发送 |
| 发送消息并停止生成 | 显示流式内容，停止按钮可点击；可重新编辑最后一条用户消息 |
| 打开模型选择、输入 @ 或 / | 弹层可见、可滚动，选择条目有效 |
| 查看长链接、代码、宽表格、图片、地图 | 普通文本换行，宽内容在各自区域查看，不撑宽整页 |
| 新会话页面打开键盘、横竖屏切换 | 欢迎区可以滚动，输入框可达，无顶部内容永久截断 |
| 切换深色模式 | 抽屉、遮罩、输入框和正文使用现有主题 |
| 返回桌面宽度 | 恢复桌面导航和并排侧栏布局，Enter 发送、Shift+Enter 换行 |

当前仅确认类型检查与生产构建结果；不编写 UI 单元测试。
