# 个人记忆同步与远端聊天

个人记忆跨项目、跨设备共享；项目记忆留在执行该项目的机器。本地打开远端聊天时，历史消息从远端加载，继续对话仍在远端项目执行。切换来源不会复制项目、聊天日志或项目记忆。

## 配置

1. 云端与桌面端都更新到包含此功能的版本。
2. 构建云端前端和服务：

   ```sh
   cd src/interface/desktop/web
   npm ci
   npm run build
   cd ../../../..
   cargo build --release --features server
   ```

3. 启动云端服务，设置 `SHIRLEY_SERVER_TOKEN` 为自己的长随机令牌。监听非回环地址时，未设置令牌会拒绝启动。例如已有 HTTPS 反向代理的部署可使用：

   ```sh
   SHIRLEY_SERVER_ADDR=127.0.0.1:8787 SHIRLEY_SERVER_TOKEN='<自己的访问令牌>' ./target/release/Shirley --server
   ```

   反向代理需要转发 `/api/`，支持长连接 SSE，关闭事件流缓冲。远端客户端要求 HTTPS；本机 `localhost`、`127.0.0.1`、`[::1]` 允许 HTTP。

4. 桌面顶栏点击“本地”，填写云端地址、访问令牌，保存并检查连接。改变地址时必须重新提供令牌，不会把旧令牌转交给新地址。
5. 勾选“共享个人记忆”并保存；点击“立即同步”可查看结果。应用启动后每 30 秒同步一次，在开始对话和完成记忆整理后也会尝试同步。对话前的同步最多等待 3 秒，失败后使用本地副本。
6. 点击“加载远端聊天”浏览远端项目和聊天列表。点击“使用本地”恢复本地列表。切换会重新加载页面；有草稿、图片附件或待发消息时，需先发送或清空。正在运行的对话留在原机器执行。

浏览器直接打开云端地址时，输入同一个访问令牌。浏览器令牌只保存在当前页面会话的 `sessionStorage` 中；桌面令牌保存在本机 `~/.shirley/remote.json`，Unix 权限为 `0600`，不返回给前端。桌面的命令与 SSE 通过本地进程转发，不依赖跨域配置。

旧版通过开发者工具设置的 `shirley.serverUrl` 不再选择远端连接；改用顶栏连接入口。连接地址和共享开关由本地原生进程统一管理，TUI 同样读取该配置。

## 旧记忆迁移

旧版解析器把缺少 `domain` 的记录视作个人记忆；同步器不会沿用这个默认值。

- 点击“审查本地旧记忆”或“审查云端旧记忆”。
- 展开全文，逐条勾选属于个人的内容，再点击“确认所选为个人记忆”。默认不选中任何条目。
- 确认时校验审查版本；期间内容发生变化会拒绝确认，需要重新加载。
- 明确标为项目的条目不会出现在个人确认列表中。无法确认归属的旧条目留在原机器。后续统计或整理回写也不会自动替旧条目确认个人归属。

现有 `core.md` 的手写内容不会单独上传；它是条目投影。需要共享的内容应先成为可审查的个人记忆条目。

## 存储与一致性

```text
~/.shirley/
  remote.json                         # 云端地址、访问令牌、共享开关
  remote-sync-status.json             # 最近尝试/成功时间、错误、计数
  memory/
    {facts,preferences,episodic,procedures}/*.md  # 个人条目及本地离线副本
    .write.lock                       # 跨进程写锁
    .sync-ledger.json                 # 已见过的条目，包含删除标记
    .sync-client-<server-id>.json      # 对应云端的同步基线
    sync-conflicts/<id>.json           # 冲突原始双方版本（含删除意图）
  workspaces/<workspace-id>/memory/    # 项目记忆，不参与同步
```

只有全局记忆目录中明确标为 `domain: personal` 的条目参与同步。协议不读取项目记忆目录，不传输聊天日志、模型配置、索引文件或向量。`core.md`、`index.md` 按本机条目重建；条目更新或删除会使本机对应旧向量失效，项目向量缓存保持独立；下载后立即可用关键词检索，语义向量在下次本机记忆整理时补齐。使用次数和 utility 保留为本机统计，不影响共享版本。

新提取的条目若未明确给出归属，默认留在项目。后台整理禁止跨个人/项目域合并、替代或改变已有归属，也不会自动激活尚未审查的同步冲突。模型仍可能误判新条目的语义归属；归属字段约束不是自动隐私脱敏。

同步使用内容版本与三方基线：本地未变则拉取云端；本地变更携带其上次云端版本。版本不同不覆盖云端：保存双方原文，竞争的非空版本另存为 `unconfirmed` 条目，待审查后再激活。删除标记持续保留，离线设备持有旧版时无法直接把已删除条目恢复为有效版本。涉及删除的冲突也保存完整记录。

冲突原文在 `memory/sync-conflicts/` 中。确认正确内容后更新对应条目；若使用竞争条目，应显式调整其状态并处理被替代的条目。历史冲突归档需在核对后自行清理；界面计数是本机保留的冲突记录数，不代表模型已自动解决。不要删除同步基线或删除标记来“解决”冲突，否则会失去离线版本判断依据。

原始证据引用保留为 `shared-evidence:` 引用，避免远端记忆错误读取本机同名聊天；原始聊天正文不随记忆上传。导入条目的证据核验会如实显示来源机器/项目的证据不在当前环境。远端聊天通过聊天接口独立加载。

写入使用跨进程 OS 锁和临时文件替换。HTTP 等待期间不持磁盘锁；如果后台整理在网络请求中途修改了本地条目，保留该修改供下一轮同步。模型整理提交前检查原始条目是否变化，避免旧推断覆盖新收到的云端版本。文件损坏、重复 ID、符号链接或同 ID 的未确认条目会阻止同步并保留离线副本，错误显示在连接面板。

## 接口

所有 `/api/cmd/*` 和 `/api/memory/*` 请求使用 `Authorization: Bearer <token>`。SSE 原生客户端使用同样的请求头；浏览器 EventSource 使用 `/api/events?token=...`。查询参数令牌仅对事件接口有效。

- `POST /api/memory/sync`：`{ changes: [{ id, expected, content }] }`，返回当前记录、冲突和排除数量。`content: null` 表示删除；新建的 `expected` 为 `null`。
- `POST /api/memory/review`：列出待确认旧记忆的全文和版本。
- `POST /api/memory/confirm-personal`：`{ approvals: [{ id, revision }] }`，确认此前审查过的条目。
- 现有项目、会话、工具命令保持原语义。`agent_subscribe` 响应附带 `sequence`，事件也带序号，客户端丢弃快照已包含的事件。
- SSE 断开后自动重连并重载当前聊天快照；事件队列溢出时发送 `resync`，要求重新加载快照。

当前为单用户自托管连接。同一令牌可以操作该服务进程可访问的项目；没有账号体系、项目目录白名单或多租户隔离。个人记忆共享要求连接同一用户拥有的服务。

## 手动验收（界面尚未经用户验证）

禁止新增 UI 单元测试；以下界面行为需要用户实际验证。

| 改动点 | 手动步骤 | 预期结果 |
| --- | --- | --- |
| 云端连接 | 顶栏打开连接面板，输入错误令牌保存，再改为正确令牌 | 错误令牌报错且不替换现有配置；正确令牌保存成功 |
| 旧记忆审查 | 分别查看本地和云端旧记忆，展开全文，只确认一条个人记录 | 默认无选中项；仅所选条目开始参与共享，其他条目保留原样 |
| 跨项目个人记忆 | 开启共享并立即同步，在另一台设备、另一项目中询问已确认偏好 | 可检索同一份个人偏好；当前项目仍使用自身记忆 |
| 项目隔离 | 在本地项目记忆中写入独特项目事实，执行同步，再到云端另一项目查询 | 同步结果不包含该项目条目；远端不会通过个人记忆获得它 |
| 远端聊天 | 点击“加载远端聊天”，打开已有远端聊天，发一句消息 | 显示远端历史，回复在远端执行；文件搜索、工具和项目记忆来自远端 |
| 快速切换聊天 | 连续点击不同远端聊天，尤其是正在生成回复的聊天 | 最后选择的聊天保持前台；历史和增量不串线、不重复 |
| 切回本地 | 清空草稿/附件/待发消息，点击“使用本地” | 恢复本地项目和聊天；远端运行任务继续运行 |
| 草稿保护 | 输入文字、添加图片或保留待发消息后尝试切换来源 | 切换按钮禁用，提示先发送或清空 |
| 离线与恢复 | 断开云端连接，在本地继续聊天并产生个人记忆，再恢复连接并同步 | 本地聊天使用缓存；恢复后补同步；错误与上次成功时间可查看 |
| 实时连接恢复 | 查看远端生成中的聊天时短暂断网，再联网 | 显示断开状态；自动重连并重载当前快照，保留输入草稿 |
| 冲突 | 两端离线修改同一条已同步记忆，先后联网同步 | 不静默覆盖；云端版保留，另一版本以待确认状态和冲突归档保留 |
| 浏览器登录 | 直接打开云端地址，输入错误/正确令牌 | 错误被拒绝；正确后加载聊天；刷新当前页面会话可继续访问 |

自动验证覆盖同步协议、并发写入、删除与冲突、旧记录审查、项目隔离、来源证据隔离、鉴权和事件流解析。类型检查、前端构建和 Rust 编译不等同于界面验收。
